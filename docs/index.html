Home Assistant Kiosk Browser

KioskZen

A fullscreen Android kiosk app designed for Home Assistant dashboards, with GeckoView support for better camera and media compatibility.

Download APK Release Notes Source Code

Reliable Kiosk Mode

Immersive fullscreen, keep-screen-on option, auto-reload after crashes or network loss, and boot auto-start.

Engine Flexibility

Switch between GeckoView, WebView, and Chromium-style profile from settings without leaving the app.

Security Focused

Hardened defaults with stricter permissions, backup protection, origin checks, and stronger password storage.

Parts of this codebase were built with AI-assisted tooling, then reviewed and adjusted manually.
